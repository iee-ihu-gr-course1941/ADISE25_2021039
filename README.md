# ADISE25_2021039
xeri
## Περιγραφή Παιχνιδιού

Η παρούσα εργασία υλοποιεί ένα διαδικτυακό παιχνίδι καρτών «Ξερή» για δύο παίκτες.
Οι παίκτες συνδέονται μέσω web browser, επιλέγουν ρόλο (P1 ή P2) και παίζουν
εναλλάξ σύμφωνα με τους κανόνες του παιχνιδιού. Η εφαρμογή βασίζεται σε αρχιτεκτονική client–server.  
Η επικοινωνία μεταξύ frontend και backend γίνεται αποκλειστικά μέσω HTTP
αιτημάτων (AJAX) και ανταλλαγής δεδομένων σε μορφή JSON. Η κατάσταση του παιχνιδιού, οι παίκτες, τα φύλλα των παικτών, το deck, οι κάρτες στο τραπέζι και οι ξερές αποθηκεύονται σε βάση δεδομένων MySQL/MariaDB. Το backend είναι υλοποιημένο σε PHP και παρέχει REST-like API endpoints, ενώ το
frontend χρησιμοποιεί JavaScript και jQuery. Το παιχνίδι παίζεται από δύο παίκτες (P1 και P2) με μία τράπουλα 52 φύλλων.
Κατά την έναρξη του παιχνιδιού, το deck ανακατεύεται και μοιράζονται φύλλα
στους παίκτες. Στον πρώτο γύρο 4 φύλλα κάτω και 6 στον κάθε παίκτη ενώ στους υπόλοιπους μονο 6 φύλλα στον κάθε παίκτη και ό,τι έχει μείνει στο τραπέζι από τον προηγούμενο γύρο. Οι παίκτες παίζουν εναλλάξ, ρίχνοντας ένα φύλλο στο τραπέζι. Αν το φύλλο που
παίχτηκε ταιριάζει σε αξία με το τελευταίο φύλλο του τραπεζιού ή είναι βαλές,
ο παίκτης κερδίζει τις κάρτες του τραπεζιού και προστίθενται στο σκορ του. Αν υπάρχει μόνο ενα φύλλο κάτω και το φύλλο που
παίχτηκε ταιριάζει σε αξία με αυτό τότε γίνεται ξερή. Οι πόντοι δίνονται σύμφωνα με τους κανόνες του παιχνιδιού ξερή.
Το project ελέγχει:
- τη σειρά παιξιάς,
- τη κατάσταση του παιχνιδιού,
- την εγκυρότητα της κίνησης,
- το τέλος του παιχνιδιού/γύρου,
- και περιπτώσεις αδράνειας (deadlock ή timeout).
Το παιχνίδι ολοκληρώνεται όταν τελειώσουν τα φύλλα και υπολογίζεται το τελικό
σκορ για την ανάδειξη νικητή.
## Περιγραφη API
## 1. Deck
### 1.1 Reset παιχνιδιού

POST /~iee2021039/ADISE25_2021039/lib/deck.php?action=reset

Αρχικοποιεί το παιχνίδι:
επαναφέρει όλα τα φύλλα της τράπουλας, αδειάζει τα φύλλα των παικτών, αδειάζει τα φύλλα του τραπεζιού, θέτει το παιχνίδι σε κατάσταση dealing και ορίζει σειρά στον παίκτη P1.

Request: Params
| Key               | Value                       | Required   |
| ----------------- | --------------------------- | ---------- |
| action            | reset                       | yes        |

Response (JSON)
```json
{
  "success": true,
  "message": "Game reset"
}
```
### 1.2 Μοίρασμα φύλλων

POST /~iee2021039/ADISE25_2021039/lib/deck.php/?action=deal

Μοιράζει φύλλα στους παίκτες και ξεκινά τον γύρο.
Αν είναι 1ος γύρος(1) τοποθετούνται 4 φύλλα στο τραπέζι αλλιώς όχι(0).
Ελέγχει ότι το παιχνίδι είναι σε κατάσταση dealing, ότι υπάρχουν ακριβώς 2 παίκτες, ότι υπάρχουν αρκετά φύλλα στην τράπουλα, μοιράζει 6 φύλλα σε κάθε παίκτη, θέτει το παιχνίδι σε κατάσταση playing και ορίζει σειρά στον P1.

Request: Params
| Key               | Value                       | Required   |
| ----------------- | --------------------------- | ---------- |
| action            | deal                        | yes        |
| first             | 1 or 0                      | yes        |

Response (JSON)
```json
{
  "success": true,
  "first_round": true
}
```
## 2. Game Termination
Τερματισμός και πλήρες reset παιχνιδιού

POST /~iee2021039/ADISE25_2021039/lib/end_game.php

Τερματίζει το τρέχον παιχνίδι και επαναφέρει την εφαρμογή στην αρχική κατάσταση.
Η λειτουργία χρησιμοποιείται: όταν ολοκληρωθεί το παιχνίδι ή όταν υπάρξει aborted παιχνίδι
Επαναφέρει την τράπουλα, τα χέρια και το τραπέζι, διαγράφει όλους τους παίκτες, μηδενίζει τα σκορ, διαγράφει τις ξερές και θέτει το παιχνίδι σε κατάσταση not_active.

Request
Δεν απαιτείται body ή parameters.

Response (JSON)
```json
{
  "success": true
}
```
## 3. Game State
Ανάγνωση κατάστασης παιχνιδιού παίκτη

GET /~iee2021039/ADISE25_2021039/lib/game_state.php

Επιστρέφει την τρέχουσα κατάσταση του παιχνιδιού για τον συνδεδεμένο παίκτη. (την κατάσταση του παιχνιδιού, ποιος παίκτης έχει τη σειρά, τα φύλλα του παίκτη, τα φύλλα στο τραπέζι και πόσα είναι και πόσα φύλλα έχει ο αντίπαλος)
Η κλήση απαιτεί authentication μέσω token.

Request: Headers
|Key                | Value                       | Required   |
| ----------------- | --------------------------- | ---------- |
| X-TOKEN           | το token που έχει ο παίκτης | yes        |

Response (JSON)
```json
{
  "status": "playing",
  "turn": "P1",
  "my_hand": [
    { "card_id": 12, "value": "A", "suit": "H" }
  ],
  "table_cards": [
    { "card_id": 7, "value": "K", "suit": "S" }
  ],
  "table_count": 1,
  "opponent_cards": 5
}
```
## 4. Game Status
Ανάγνωση κατάστασης παιχνιδιού

GET /~iee2021039/ADISE25_2021039/lib/game_status_api.php

Επιστρέφει την τρέχουσα γενική κατάσταση του παιχνιδιού(κατάσταση παιχνιδιού, ποιος έχει σειρά, τον νικητή αν εχει βγει ακόμα, την τελευταία αλλαγή κατάστασης και τα σκορ των 2 παικτών) χωρίς να απαιτέι τίποτα(body,parameters). Το αρχείο game_status.php είναι βοηθητικό για εδώ, υλοποιεί την λογική διαχείρισης κατάστασης του παιχνιδιού και περιλαμβάνει συναρτήσεις για: ανάγνωση της κατάστασης παιχνιδιού, εμφάνιση της κατάστασης σε JSON, μετάβαση καταστάσεων ανάλογα με τους παίκτες ή αν τελείωσε το παιχνίδι και ανίχνευση αδρανών παικτών και abort.

Request
Δεν απαιτείται body ή parameters.

Response (JSON)
```json
[
  {
    "status": "playing",
    "turn": "P1",
    "result": null,
    "last_change": "2026-01-20 18:42:10",
    "score_p1": 0,
    "score_p2": 0
  }
]
```
## 5. Play Card
Παίξιμο φύλλου

POST /~iee2021039/ADISE25_2021039/lib/play_card.php

Ο παίκτης παίζει ένα φύλλο από αυτά που έχει.
Ελέγχει το token του παίκτη, ελέγχει αν είναι η σειρά του και την ενημερώνει, εφαρμόζει τους κανόνες του παιχνιδιού (μάζεμα, ξερές), ελέγχει τις διαθέσιμες κάρτες, αφαιρεί αυτές που παίχτηκαν, ενημερώνει το τραπέζι, ενημερώνει την κατάσταση του παιχνιδιού και την τελευταία φορά που έπαιξε ο κάθε χρήστης και ελέγχει αν τελείωσε ο γύρος ή το παιχνίδι, ενημερώνει το σκορ και βγάζει νικητή.

Require: Headers
| Key               | Value                       | Required   |
| ----------------- | --------------------------- | ---------- |
| X-TOKEN           | token παίκτη                | yes        |

Require: Json body
| Field             | Description                 | Required   |
| ----------------- | --------------------------- | ---------- |
| card_id           | Το ID του φύλλου            | yes        |

Response (JSON)
```json
{
  "success": true,
  "collected": true,
  "xeri": false,
  "xeri_type": null
}
```
## 6. Players
Login

POST /~iee2021039/ADISE25_2021039/lib/players.php

Καθορίζει τον παίκτη (P1 ή P2) με username και δημιουργεί token. Ελέγχει αν ο παίκτης που θέλω να επιλέξω είναι ενεργός τα τελευταία πέντε λεπτά και αν είναι μου βγάζει αντίστοιχο μήνυμα αλλιώς συνδέομαι κανονικά. Επίσης ενημερώνει την κατάσταση του παιχνιδιού. Το token επιστρέφεται και πρέπει να χρησιμοποιείται σε επόμενα requests.

Request: Json body
| Field             | Description                 | Required   |
| ----------------- | --------------------------- | ---------- |
| player            | P1 or P2                    | yes        |
| username          | το όνομα χρήστη του παίκτη  | yes        |

Response (JSON)
```json
{
  "success": true,
  "player": "P1",
  "username": "user1",
  "token": "generated_token"
}
```
